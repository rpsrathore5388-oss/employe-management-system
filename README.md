# Employee Management System

A React-based employee task management application.

## ✨ Features

### Admin
- Create tasks
- Assign tasks
- Monitor employees
- View task statistics

### Employee
- View assigned tasks
- Accept tasks
- Complete tasks
- Mark tasks as failed
- Track productivity

## 🛠️ Tech Stack

React
Vite
Tailwind CSS
Context API
LocalStorage
